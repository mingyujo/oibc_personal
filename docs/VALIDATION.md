# 검증 범위

실제 데이터값·식별자·좌표·행별 예측은 이 문서에 포함하지 않습니다.

## 로컬 검증

- Windows/Python3.12의 기존 환경에서 CPU 경로를 검사합니다. 테스트에 사용한 코어 패키지 버전은 requirements-tested.txt에 있습니다.
- 실제 데이터의 작은 표본에서 새 RAW6의262개 열과 정답 정규화 값이 기존 검증 캐시와 NaN 위치까지 정확히 일치하는 것을 확인했습니다. 이는 전체 기간 전수 재검증이나 새 모델 성능 입증은 아닙니다.
- 공개 테스트는 전부 가상의 발전소·기상·발전량을 생성합니다. 원본 데이터를 다운로드하거나 CI에 업로드하지 않습니다.
- 테스트는 시간 경계/윤일·자정, 결측 정답, 예보 회차 부재와 항목 결측의 구분,17시 부재시10시fallback, 비정시 예보 제외, 주변시간의 대상일 경계,0하한 선택지표, 중복 실행 잠금, 캐시 재사용, 모델 단계 재개, 파일 변조 탐지, 학습 뒤 평가, 공식형식 예측 생성, 상세CSV 경로 제한을 다룹니다.
- 트리3종과 선택적 신경망2종은 작은 합성 데이터로 선택→재적합→로드→추론을 실행합니다. 적합 단계의 성공과 장기 실제데이터 성능은 구분합니다.

## 다른 컴퓨터에서 먼저 실행

CSV 채점 확장(v0.3.0)은 전체30개 합성 테스트를 제공합니다. 집합/발전소 CSV의 같은 S·W, 채점 가능 시간 누락 차단, 원 단위 반올림과 원본 정밀도 보존, 파일 중복·변조 탐지, HTTP 업로드·외부 Origin 거부,187개 기록 표·170개 재채점 집계, 데이터 지문 불일치 시 과거 점수 자동 병합 차단을 추가로 확인합니다. 재채점 집계에는 시간별 예측이나 원본 키를 넣지 않습니다.

테스트베드 확장(v0.2.0)에는 정산식 손계산, 집합 안/밖 오차 상쇄, k의 종료시각 경계·자정·0원 가격, 전체 정답 공통 지원, 배정 용량·누락·중복, 제출8,760시각·타임존·17,520행·비정상값, 고정 마지막1년 설정, 배정만 바꾼 후보의 모델 재사용, 평가 재개·변조 탐지, 동일 표본 통계를 검사하는 합성8개를 추가했습니다. 전체22개이며 선택적 신경망 검사는 PyTorch 설치 여부를 따릅니다.

```bash
python -m oibc_portable doctor
python -W ignore::DeprecationWarning -m unittest discover -s tests -q
python tools/check_release.py
```

PyTorch를 설치하지 않으면 신경망 테스트는 명시적으로 건너뜁니다. CPU 트리 테스트는 실행됩니다. GitHub Actions는 Windows/Linux에 CPU 테스트를 구성했으며, 로컬 검사 성공만으로 원격CI 성공이라고 기록하지 않습니다.

일부 NumPy/pandas 조합에서 날짜 연산의DeprecationWarning이 발생할 수 있습니다. CLI는 stderr와 상세 오류를 로컬 로그에 보관합니다. 경고를 숨긴 테스트 명령도 실패의 종료 코드를 유지합니다. GPU 실행·다른OS·대규모 메모리 사용은 해당 장비에서 확인해야 합니다.
