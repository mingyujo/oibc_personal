# CSV만 넣어 채점·비교하기

기준 배정을 그대로 썼다면 **예측 CSV 하나**를 넣으면 됩니다. 발전소 배정을 바꿨다면 배정 CSV도 함께 넣습니다. 테스트베드가 제공 자료의 실제 발전량과 SMP를 읽어 W·S를 계산하므로 모델을 다시 학습할 필요가 없습니다.

## 화면 열기

설치한 저장소 폴더에서 실행하고 마지막에 표시되는 `http://127.0.0.1:8765`를 브라우저에서 엽니다.

```powershell
.\.venv\Scripts\python.exe -m oibc_portable testbed serve --data-dir 'D:\OIBC\01_participant_dataset' --work-dir 'D:\OIBC-csv-testbed'
```

화면에서 예측 CSV를 여러 개 선택하고 **CSV 채점**을 누릅니다. 단일 결과는 이름을 직접 지정할 수 있습니다. 배정 파일이 없으면 제공된 A/B 참조 배정을 사용합니다. 다른 배정이면 같은 화면에 배정 CSV를 선택합니다. 서로 다른 배정의 결과는 각각 해당 파일을 지정해서 추가합니다.

서버는 이 PC의127.0.0.1에만 열립니다. 업로드한 원본 행은 외부 서버로 전송하지 않고 `.local-only/details/`에 보관합니다. 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다. 이미 사용 중인 포트면 `--port 8766`처럼 바꿉니다.

## CSV 형식

- 집합별 예측: `group, ts, forecast_kwh` — G1·G2의 시간별 합계(kWh).
- 발전소별 예측: `site_id, ts, forecast_kwh` — 해당 시각의 개별 발전량(kWh). 테스트베드가 배정에 따라 합산합니다.
- 배정 파일: `site_id, group` — 제공 발전소 전부를 정확히 한 번 배정하고 각 집합20MW 이상이어야 합니다.

`pred_kwh`와 `prediction_kwh`도 예측값 열의 별칭으로 받습니다. 정규화된 값이나 kW를 kWh로 추측해서 변환하지 않으므로 반드시 kWh 단위로 저장해야 합니다. 시각은 명시적 타임존이 있는 정시 종료시각이고 값은 유한한0이상이어야 합니다.

테스트 대상일은 **2024-06-01~2025-05-31**이며 종료시각은 **2024-06-01 01:00~2025-06-01 00:00 KST**입니다. 기간 밖·중복·잘못된 배정·음수·NaN·무한대는 거부합니다. 채점 가능한 모든 시각의 두 집합/모든 발전소 예측을 포함해야 하며, 어려운 시각을 빼서 점수를 높일 수 없습니다.

예측이8,760시각 전부 있으면 ‘전체 시각’으로 표시합니다. 원본 정답이 없는 시간의 예측이 빠졌더라도 **모든 전수 정답 시각을 빠짐없이 포함**하면 과거 W·S 계산은 가능하며 ‘채점 가능 시각 포함’으로 표시합니다. 이 허용은 과거 테스트 채점에만 적용됩니다. 공식 제출은별도의 `validate-submission` 명령으로8,760시각·17,520행 전체를 검사해야 합니다.

## 표시와 계산

W·S·R, 금액 차이와 구간은 **소수점 없이 원 단위 반올림**으로 표시합니다. 내부 JSON과 순위 계산은 반올림 전 정밀도를 유지합니다. ‘비교표 CSV 저장’도 원 단위 정수로 내보냅니다. 과거 기록에서 백만원·만원·천원 단위로 제시한 표는 화면에서 원 단위로 환산합니다. MAE·비율·퍼센트까지 정수로 바꾸지는 않습니다.

같은 원본253개소가 모두 관측된 **3,802시간**을 공통으로 정산합니다. 매전수익 R이 같은 표본에서는 S 증가가 W 감소와 같습니다. 1년 전체 관측이 있는205개소는 별도 코호트 진단이며253개소 정산을 대신하지 않습니다.

CSV만으로 모델·배정이 언제 만들어졌는지 입증할 수는 없습니다. 마감을 입력하지 않으면 ‘미확인’이며, 입력해도 제작자의 선언으로 표시합니다. 모델 학습과 배정 제작이 모두 선언 시점 이전이어야 합니다. 선언 시점이2024-05-31 00:00 KST 이후면 고정 테스트 계약에 맞지 않아 거부합니다. 이미 조회한 과거 기간의 개발 비교이며 자동 모델 승격·실제 서버 제출은 하지 않습니다.

## 기존 결과 모두 보기

- EXP-001~026의 전체 원문 기록은 그대로 보존합니다.
- ‘기존 전체 실험·결과’ 탭에서 **187개 결과·기록 표, 총1,456행**을 실험별·모델별로 검색합니다. 계획·환경·진행 중 기록도 출처와 함께 남아 있습니다. EXP-026의 최종 완료나 승격을 가정하지 않습니다.
- 저장된 예측과 기존 고정 결합 정책 중 마지막1년을 동일하게 재채점할 수 있는 **170건**을 CSV로 변환해 재채점했습니다. 단일 모델, 시드, 고정 결합 등 여러 종류의 결과이며170개 서로 다른 모델 구조라는 뜻은 아닙니다.
- 원본 데이터 지문이 같은 PC에서는 이170건의 집계 점수를 CSV 비교 표에 자동으로 보여줍니다. 원본 데이터가 다르면 같은 순위에 섞지 않고 과거 기록 탭에서 조회합니다.
- 과거 레시피들은 입력·학습 설정이 다를 수 있습니다. 결과가 좋다는 사실을 모델 구조 하나의 우월함으로 해석하지 않습니다. 저장된 예측을 다시 계산한 것으로 재학습은0회입니다.

패키지에 넣는 것은 집계 W·S·월별 결과입니다. 원본 데이터·발전소 식별자·좌표·시간별 예측 CSV·가중치를 GitHub에 넣지는 않습니다. 실제 CSV 원본은 해당 PC의 `.local-only/`에서 보존합니다.

## 명령으로 채점하기

```powershell
.\.venv\Scripts\python.exe -m oibc_portable testbed score-csv --data-dir 'D:\OIBC\01_participant_dataset' --forecast 'D:\results\model.csv' --label 'my-model' --work-dir 'D:\OIBC-csv-testbed'
```

필요하면 `--composition 'D:\results\composition.csv'`와 `--trained-through '2024-05-31'`을 추가합니다. 여러 CSV는 `--forecast` 뒤에 공백으로 이어서 지정합니다. 실행 중인 화면 서버와 같은 작업 폴더를 명령으로 동시에 수정하려 하면 잠금으로 막습니다. 서버를 종료하거나 별도 작업 폴더를 사용합니다.

[기존 모델 학습형 테스트베드](TESTBED.md)도 함께 사용할 수 있습니다. CSV를 이미 가지고 있다면 이 문서의 채점 경로가 바로 값을 계산하는 방법입니다.
