# 모델 검토와 새 레시피

이 패키지는 기존 연구 파이프라인을 검토한 후 과거 실행 폴더 의존성을 제거한 새 구현입니다. 원본 데이터나 기존 가중치는 포함하지 않습니다.

## 반영한 변경

1. **내부 검증의 가용 시점.** 대상일 예측 원점은 전날17시KST입니다. 기존 보존 RMSE 모델의 내부 검증에서는 첫 원점 이후 정답7시간분이 적합에 포함된 사례가 확인됐습니다. 새 구현은 검증30일 앞에 대상일 하루를 비우고, 선택 적합 정답의 종료 시각을 첫 검증 원점 이전으로 제한합니다. 선택 뒤 재적합은 최종 마감까지의 가용 정답을 사용합니다.
2. **실제 출력과 선택 지표.** 모든 모델은0하한을 적용한 예측으로 용량 가중 MAE를 계산해 조기 종료합니다. 트리의 원래 내장MAE로 선택하고 추론에만0하한을 쓰던 차이를 정리했습니다. LightGBM은 기본 metric을 끄고 custom feval을, CatBoost는 custom eval_metric을 사용합니다.
3. **모델 목적을 명시.** LightGBM-MAE·CatBoost-MAE는 용량 가중 정규화 절대오차를, CatBoost-RMSE는 비가중 정규화 제곱오차를, 신경망은 비가중 정규화MSE를 학습합니다. 구조만의 통제 비교가 아닌 레시피 비교입니다. 개별 오차 개선과 두 집합 정산W 개선을 구분합니다.
4. **완전한 기상 제거 대조.** `no_weather`는 메타·달력·태양15개만 유지합니다. 예보의 현재값·주변시간·요약·결측/품질·회차fallback까지 제거한 뒤 재학습합니다. 메타의 위치정보와 태양 계산은 유지합니다.
5. **이식성·보존.** 데이터는 인수로 받고 코드 안의 개인 경로나 과거 캐시를 참조하지 않습니다. 원본은 수정하지 않습니다. 월별 캐시, 실행 잠금, 설정·코드·파일 해시와 단계별 완료 마커로 재개를 관리합니다. 모든 상세 출력은 로컬 전용입니다.

## 중요도95%의 해석

이전 LightGBM-MAE18개에서 태양 변수군의 누적gain 비중은95.25%였지만, 분할 사용 횟수 비중은20.47%였습니다. 각 나무 첫 분할의gain이 전체92.06%를 차지했고 첫 분할은 거의 모두 태양 관련이었습니다. 이 값은 발전량 설명률이나 실제 예보 추가 기여율이 아닙니다. CatBoost PredictionValuesChange와도 직접 비교할 수 없습니다.

이 결과로 모델을 정상·오류 또는 기상을 무시하는 모델이라고 단정하지 않습니다. 이후 시간 구간에서 `raw6`와 `no_weather`의 예측 오차·주간 오차·정산을 비교해야 합니다.

## 한계

- 새 코드로 대회 데이터의 장기 학습·성능 승격을 완료한 것은 아닙니다. 기존 모델 점수를 새 코드의 성능으로 옮기지 않습니다.
- 고정된 모든 설정이 최적이라는 근거는 없습니다. 신경망의 제한된 레시피 탈락은 신경망 계열 전체의 실패가 아닙니다.
- 기상 예보의 관측 연관성·변수 제거 효과·물리적 인과효과는 서로 다릅니다.
- 이 패키지는 기존 이력/경험 스케일 보정·조건부 게이트·집합 최적화를 자동 수행하지 않습니다. 검증된 기본 예측과 비교 대조를 제공합니다.
